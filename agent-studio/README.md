# Agent Studio

**Audience:** Agent blueprint authors and publishing reviewers.

This area is the navigation home for reusable blueprints, versions, capability declarations, reviews and publishing journeys.

[Open the illustrative clickable gallery](../prototype-gallery/index.html) · [Repository guide](../docs/README.md)

## How to review
1. Select **Agent Studio** in the gallery.
2. Explore catalog, editor and publish review example screens.
3. Inspect simulated failure and access states.
4. Compare proposals with actual blueprint specifications, versioning rules and approval requirements before implementation.

**Migration status:** Historical sprint assets have not yet been moved here.
