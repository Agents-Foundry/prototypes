# Agents Foundry — Product Prototypes

Canonical design-first workspace for Agents Foundry. This repository contains visual mockups, screen registries, user journeys, review records, and design specifications. **No application implementation code belongs here.**

## Principles

- Mockups and interaction specifications are the product source of truth after review and approval.
- Screens have stable IDs and are organized by product surface and capability.
- Draft visuals are not approved or implementation-ready.
- Every approved screen includes its states, accessibility, permissions, and acceptance criteria.
- Design changes use reviewable pull requests; never silently revise approved assets.

## Product surfaces

- `platform-owner/` — SaaS operator console.
- `organization-admin/` — Organization onboarding, hierarchy, workforce, governance.
- `employee-desktop/` — Human–AI employee desktop experience.
- `agent-studio/` — Reusable blueprints and agent publishing.

See the Sprint 01 design branch for the initial registry and conventions.
