## Review hierarchy

1. Locate the product surface and the user journey.
2. Find stable screen IDs and their interaction/state specifications.
3. Trace the product decision and related review records.
4. Inspect test evidence with exact commit SHA and provenance.
5. Distinguish automated checks from independent security, accessibility, visual, and product-owner approvals.
