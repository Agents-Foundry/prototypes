# Employee Desktop

**Audience:** Employees collaborating with AI agents.

Use this area for conversations, delegated work, approvals, progress, interruption, cancellation, recovery and cross-device continuity journeys.

[Open the illustrative clickable gallery](../prototype-gallery/index.html) · [Repository guide](../docs/README.md)

## How to review
1. Select **Employee Desktop** in the gallery.
2. Explore workspace, agent run and approval checkpoint example screens.
3. Switch between normal, offline and permission-denied scenarios.
4. Trace intended fail-closed actions, fresh authorization and safe replay behavior to approved decision records. A simulated confirmation is not an actual approval.
