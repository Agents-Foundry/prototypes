# Sprint 03 — Employee Desktop Agent Experience

**Design foundation — DRAFT, not frozen.**

The independent cross-platform agent window supports employees working with assigned AI agents using organization-governed tools such as Jira, Bitbucket, browser automation and secure credentials.

This PR proposes 16 screens, 10 product-owner decisions, QA Engineer day-one user journeys and initial light/dark workspace visuals. No OS shell, API, secrets vault, app backend or runtime is implemented.

**Design prerequisite:** UX flows and mockups are product source of truth **before** application development. Sprint 02 independent security, accessibility and design freeze remain pending and must not be silently carried forward as accepted.
