# Organization Admin

**Audience:** Administrators of customer organizations.

This area is the canonical navigation home for onboarding, organizational hierarchy, teams, roles, workforce and governance journeys.

[Open the illustrative clickable gallery](../prototype-gallery/index.html) · [Repository guide](../docs/README.md)

## How to review
1. Select **Organization Admin** in the gallery.
2. Explore overview, team configuration and access review example screens.
3. Check permission-denied and offline scenario states.
4. Verify intended authorization behavior against the relevant design specification; this gallery does not enforce real policies.
