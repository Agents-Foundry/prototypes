# Hire and activate an AI employee

**Actor:** organization administrator with workforce-create permission.

1. Open AI Employees. Empty state prompts first hire; existing directory supports search and status filtering.
2. Select blueprint (e.g., QA Engineer) or start from an approved blank template.
3. Configure identity, department, team, manager, runtime model/provider and budget.
4. Select skills and allowed capabilities; show potential permissions clearly.
5. Connect approved Jira, Git, testing and browser tools; surface connection-health checks. Never display stored credentials.
6. Review identity, policy restrictions, cost estimate, secrets prerequisites and missing requirements.
7. Activation can proceed only after required approvals and checks; otherwise show blocked state and remediation steps.
8. Display activation result with next actions and audit record.

Design required for loading, errors, insufficient permissions, approval pending, provider unavailable, missing credentials, and cancellation/resume.
